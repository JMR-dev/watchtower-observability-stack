# Every secret the stack uses: Secret Manager in watchtower-observe (payload
# replicated to europe-west3 only), plus a copy in gopass as watchtower/<id>.
#
#   scripts/bootstrap.sh         creates each one empty and lets
#                                watchtower-deployer@ read it, one by one
#   scripts/secret.sh put <id>   stores a value in both places
#   scripts/secret.sh check      lists the ones still without a value
#
# infra/internal/names lists the same ids, and a test keeps the two equal.
# What each one is: docs/required-secrets.md.
